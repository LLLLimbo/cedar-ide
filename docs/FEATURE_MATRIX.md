## 建议下一顺序

1. 可靠性：Windows 子进程管理、断线事务状态、草稿恢复和外部文件监听
2. 语言体验：已有自动同步/补全/跳转，继续完善 inline diagnostics、代码操作、片段与多文件编辑
3. Java/Kotlin 工程导入：真实大型 Maven/Gradle 项目与 JDK 选择、索引进度
4. DAP 调试、PTY、测试树；每个模块都有真实程序端到端验收
5. Git/重构/插件协议，再按实际使用需求扩展框架与企业工具

完成以上仍不能直接宣称与 IntelliJ IDEA 全功能等价。需要持续维护兼容矩阵、真实性能数据和长期真实项目使用反馈。
