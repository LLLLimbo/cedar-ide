# Maven 依赖来源快照

此功能用于已启动、受信任的 Windows / Linux 隔离 agent Maven 叶工程会话（Linux 扩展待 0.39 原生验收）。选择 Language 面板中的
**Inspect dependencies**，执行一次有界查询。缺少独立能力或实际服务端项目设置命令时，
按钮会说明原因；不会隐式启动服务或退回通用命令。原有 Check Maven model 保持独立。

## 读懂来源

- **POM 直接声明**：启动时磁盘 POM 中经过验证的 groupId、artifactId、version、classifier，
  以及显式值或默认值的 scope/optional。预期 JAR 路径相对于选定的本地 Maven 缓存。
- **JDT 观察**：本次服务端项目设置中实际报告的普通 library 路径，分别相对于工作区或缓存。
  与直接声明的关联来自已验证路径的匹配；大小写碰撞等多重匹配会保留全部声明并说明歧义。
- **文件存在性**：本次检查时普通文件存在或缺失。缺失 JAR 仍可能被 JDT 报告；缓存中存在
  JAR 也不代表 JDT 已报告它。这不是 JAR 内容、签名、完整性或构建成功验证。

模型尚不可用时，观察状态为未知，不能把空列表理解为“没有依赖”。有效的空观察只表示
本次没有报告 library 条目。未匹配到直接声明的 JDT 路径不会被猜测为某个传递坐标或依赖边。
本视图不是 dependency tree、版本冲突求解、有效 scope 计算或漏洞审计。

## 会话与草稿

请求和回复绑定实际启动 ID、启动时磁盘 POM SHA-256，以及前端连接/语言会话和请求序号。
后端在固定项目设置查询前后检查磁盘 POM；变化要求停止并重新启动。已确认的新磁盘 POM
版本、会话替换、断线、失去信任或较新查询会使旧快照失效。未保存的 POM 草稿及 Undo
会保留，草稿不等于已导入磁盘模型。文件和索引仍可能在查询后变化，整个观察不是文件系统原子快照。

## 边界与成本

只按需查询一次，不轮询，不保存，不构建、不重新导入、不启动工具、不导航到元数据路径，
也不解析或下载新的依赖。最多 256 个直接声明、256 个观察条目和 256 个关联，原始与最终
回复各有 128 KiB 上限；超限明确拒绝该视图，不返回被静默截断的成功结果。路径仅显示为
选定根下的相对路径，原始服务端附加字段、绝对缓存目录及 POM 全文不会进入此回复。

Maven 支持子集、可信配置代码、缓存/索引写入和公开 Gradle 元数据请求的既有限制仍见
[MAVEN_PROJECTS.md](MAVEN_PROJECTS.md)。Maven 离线解析不等于进程网络隔离或代码沙箱。
该视图不更改 512 MiB JVM 最大堆或既有请求/清理预算，也不声称降低总资源占用。
