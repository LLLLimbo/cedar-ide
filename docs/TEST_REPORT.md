That choice survives report loading/clearing, tool switches, hide/show, disconnect and reconnect. Window constraints can limit the displayed allocation without overwriting the preference; regrowth restores it when space permits. Passive hover/click, horizontal movement and another control's drag do not establish a preference. The 245-point default and 150–500 range are unchanged, and neither a hard content cap nor guaranteed editor space is promised.
