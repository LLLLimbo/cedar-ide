This pending slice extends Ctrl/Cmd+G with optional `line:column` navigation within the current buffer. It preserves valid line-only navigation and large-draft mapping. Columns are one-based Unicode scalar positions: tabs and non-BMP characters count once; combining marks count separately. They are not rendered-width or UTF-16 columns. LF separates lines; the CR in a CRLF terminator is excluded from line content. End-of-line is an allowed position, but the command cannot target the interior of CRLF. Lone CR remains content.

The whole dialog input is bounded to 32 characters including outer whitespace; column mapping is bounded to a 1 MiB buffer. Uniform atomic oversized-input refusal deliberately replaces the old numeric-only paste truncation. All valid line-only inputs and line-only mapping of larger drafts remain supported. Invalid or oversized coordinates are refused without clamping or accepting a truncated paste.
