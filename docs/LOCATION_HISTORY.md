# 已打开标签的位置历史

Back / Forward 在当前连接里仍打开的编辑器位置之间导航。可以从声明或搜索结果跳到
另一个位置，再回到离开时的完整选区；不会重新读取文件、启动语言服务或恢复已关闭
的标签。执行信任关闭时也可使用已有编辑器位置。

## 什么会进入历史

完成的显式文件打开、不同标签的主动切换、Go to Line、选择搜索/编译/诊断结果，以及
完成的语言位置跳转会记录离开的位置。只提交一次，异步请求失败或已经过时不会记录。
离开位置取自主动跳转开始时；等待过程中只移动光标不会改写该快照，编辑正文则会使
原快照失效。
如果打开结果到达的同一帧里又有键盘、点击等实际操作，较新的操作优先；普通文件仍可
作为后台标签打开，但不会抢走焦点或增加历史。仅移动鼠标、改变修饰键或松开按键不
触发此规则；完成已按下按钮的有效点击仍优先。先前等待期间的光标移动仍按上面的
快照规则处理。
点击当前标签、打开或取消选择器、普通移动光标、输入、查找下一处、撤销/重做、保存、
重载、关闭标签后的自动切换都不增加历史。新建草稿、恢复草稿和配置编辑流程也不会
因为自动激活标签而制造历史记录。

Back 和 Forward 各最多保存最近 64 个位置，满额时移除最旧位置。成功的新导航清空
Forward；同一位置的重复操作不增加记录。若目标编辑版本已达到计数上限，普通导航
仍可完成，但显示历史不可用，两个历史栈均不改变；若只有离开位置达到上限，则不
保存该离开位置，成功的新导航仍清空 Forward。位置历史只在内存中保存文档身份、编辑版本和选区信息，不额外保存
源码、路径或一份撤销历史。

## 选区与过时位置

返回复用原来的编辑器和草稿，恢复选区方向及换行处的光标位置，不修改正文、保存基线
或撤销历史。若该标签已经编辑，旧位置会明确跳过并显示数量，不把旧坐标强行套到新
文本。即使随后 Undo 恢复了相同文字，旧位置仍算过时。这是保守的版本检查，不是
跟踪源码修改的语义锚点。

跳过无效位置本身不会修改另一个方向的历史。若没有可用目标，当前标签和选区保持。
如果普通光标移动后，历史顶部恰好等于当前完整选区，Back/Forward 会移除这些重复
位置并继续找该方向上的下一个不同位置；重复项不计入“过时”数量。若全部相同，只清理重复项，
当前选区和另一个方向的历史不变，也不推入新记录。
关闭标签会移除它的位置；重新打开同一路径也不会复活旧身份。断开后仍可在现有草稿
间本地导航，显式重连或更换工作区会清空历史。

## 按钮与快捷键

编辑器中的 Back / Forward 按钮可用 Tab 聚焦、Enter 激活。快捷键为 Windows/Linux
的 Ctrl+[、Ctrl+]，macOS 的 Cmd+[、Cmd+]。不同时按 Alt 或 Shift；普通方括号输入和
AltGr 输入保持原意。没有直接方括号组合的键盘布局仍可使用按钮。

模态框、较新的输入和当前导航状态优先；一次按键不会因长按而反复跳转。此功能不切换
工具面板。操作系统或其他软件全局拦截的组合键不在应用保证范围内。

本阶段不重新打开关闭的文件、不持久保存跨会话历史，也不提供自动源码定位修复。
