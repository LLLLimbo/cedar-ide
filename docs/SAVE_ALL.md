# 显式保存全部编辑器缓冲区

在 Save 旁的 **...** 下拉菜单（提示为 **Save actions**）选择 **Save all editor buffers**，或按 **Ctrl/Cmd+Shift+S**。它保存本次操作捕获的脏标签，最多 32 个，每个最多 1 MiB，合计最多 32 MiB。普通 Save / Ctrl/Cmd+S 仍保存当前文件。

保存前检查全部候选缓冲区的身份、版本、内容大小和已知保存状态。随后按捕获的标签顺序逐个提交带原磁盘版本的 Write；新文件采用独占创建，已有同名文件会冲突，不自动创建目录。这里的预检查不读取磁盘，也不能预先保证后续文件的权限、存在性或版本仍然不变。

每次推进前重新检查所有尚未提交的候选。修改其中任何一个、关闭连接、保存冲突或异常回执都会停止后续提交。已经成功保存的文件留在磁盘上，**这不是多文件原子事务，也不会回滚先前保存**。结果区分已确认提交、未提交和结果未知，不把已确认提交数当作当前干净标签数。

在已提交文件等待回执时可以继续输入；回执只确认已提交的内容，后续输入、选区、撤销和恢复副本保留。新打开的文件不加入本次批次；需要时再显式执行一次 Save All。

菜单中的 **Cancel remaining saves** 取消剩余提交。已经发出的 Write 仍需等待回执，或按现有机制保留未知保存状态；取消不会撤回磁盘写入。批次拥有保存流程期间，普通 Save、Save profile、关闭或切换连接需要先取消并等待在途写入结束。

结果未知且原提交身份仍可核实时，保留草稿，使用现有显式核对操作。如果提交身份不可用，**Check 和继续保存保持禁用**；保留或复制草稿，并使用 Compare with disk 比较，不能从当前文本捏造原提交身份。重连或核对完成不会自动恢复旧批次，不会自动重写。结果相同的磁盘字节只能证明当前内容，不能证明原请求曾提交或物理文件身份未变。

Save All 只处理编辑器缓冲区。`cedar.tasks.json` 的原始编辑器文本可以像普通文件一样保存，但 Run 面板中尚未通过 **Save profile** 序列化的表单修改不会自动写入。Save All 不运行命令、启动语言服务或自动构建。
