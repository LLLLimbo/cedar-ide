# 按需目录树

Explorer 保留默认平面目录模式，并提供当前连接内的 Tree 模式。目录树只使用已有的
List/Read 文件操作，不增加后端能力、执行权限或服务。执行信任关闭时也能浏览。

## 展开、选择与键盘

目录只在显式展开或 Refresh 时列出；不会递归预读、自动扫描、轮询或监听文件系统。
已展开兄弟目录的上下文可以保留。选择目录时，它是 Ctrl/Cmd+P 当前目录文件和 New File
的范围；选择文件时范围是其父目录。尚未加载的范围会明确说明，不能当成空目录。
文件仍通过现有 Open 路径打开，已打开的脏稿、编辑器身份和撤销历史保持。

当目录树行拥有焦点时：

- Up/Down、Home/End 在当前可见行中选择。
- Right 展开目录，或进入已加载目录的第一个子项。
- Left 折叠目录，或选择父目录。
- Enter 打开文件，或展开/折叠目录。Tab 保留普通焦点移动。

目录区域使用滚轮、触控板或滚动条滚动；拖动内容背景不会滚动。显式键盘选择会将
目标行滚入可见区域，普通空闲帧不会把滚轮位置拉回。

这些按键不接管编辑器或模态输入。折叠祖先时，后代选择移到该祖先；已经打开的文件
不会关闭。Ctrl/Cmd+Shift+E 仍可聚焦 Explorer，Ctrl/Cmd+J 仍可隐藏工具回到编辑器。

## 有界快照与失败

目录树最多保留 64 个目录快照、4,096 行和 512 KiB 的缓存名称/路径文本，并限制深度
为 32、单一路径为 4,096 字节。名称和路径按 UTF-8 字节计数。这些是目录缓存边界，
不是整个 IDE 内存的上限。后端每次 List 的既有 4,096 条/512 KiB 上限也保持不变。

超限拒绝整份新目录回复，明确显示限制，不把截断的部分当作完整目录。可以折叠目录
释放后代缓存，或使用平面模式；不会悄悄逐出可见内容。刷新先保留旧快照，只有完整、
合法且满足预算的回复才替换它。失败后旧内容标记过时，重试必须由用户显式触发。

浏览器最多有一个 List 在途，切换模式也不排队扫描。加载中可操作已经缓存的内容，
新的目录请求需要等待；折叠、换模式或换连接后的旧回复不能覆盖较新状态。重连清除
目录缓存，保留原有编辑器草稿规则。列表中的路径只是快照；实际打开仍由后端检查。

树模式下保存文件只把对应父目录标为过时，用户可显式 Refresh 更新目录；不会意外
列出另一个当前目录。外部文件变化也不会自动反映，目录树不保证实时性。

本阶段不增加重命名、移动、删除、多根项目或依赖索引；目录元数据不能证明物理文件
身份。原生 Windows GUI 和真实 SSH 互操作仍须单独验证。
