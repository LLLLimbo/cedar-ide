Comparing those whole signatures assumes incompatible timestamp meanings. Individual native tuples were not logged, so the matching failure mechanism is source-supported rather than a captured field-level measurement.

Unix retains `st_ctime_ns`. No timestamp tolerance, inode truncation, identity bypass, new FFI or shipping Rust change is introduced. Missing Windows birthtime fails closed; unusual executable-suffixed environment filenames may still fail the existing full-mode check. This is controlled CI consistency checking, not proof against arbitrary hostile filesystem mutation. Existing 44 tests remain, with four additional synthetic tests for Windows common creation time, every retained-field mismatch including high file-ID bits, missing/invalid birthtime and Unix change-time rejection. Fresh native CI and packages remain required; actual compiler preflight has not yet passed on Windows.
